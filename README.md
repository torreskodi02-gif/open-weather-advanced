# Open Weather

A clean, open-source Flutter weather app with a custom UI.

- **Data**: Open-Meteo (no API key required)
- **Features**: Current conditions, hourly & daily forecast, settings, multiple themes, radar/map page
- **License**: MIT

## Getting the APK

1. Push this code to GitHub
2. Go to the **Actions** tab
3. Run the "Build APK" workflow (or it runs automatically on push to main)
4. Download the APK from the workflow artifacts

## Development

```bash
flutter pub get
flutter run
```
